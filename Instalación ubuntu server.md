# Instalación ubuntu server

1. Abrir VirtualBox
2. Hacer clic en "nuevo"
3. Ponerle nombre a tu máquina virtual y colocar la ISO (antes de continua, quita la instalación desatendida)
4. Luego hay que dejar la máquina virtual con 4Gb de RAM, 2-3 núcleos y 50-75Gb de almacenamiento
